# andrecorreia-vendas

Site principal de vendas: **andrecorreia01.com.br**

## Stack
- HTML estático + JS bundle
- Hospedagem: Cloudflare Pages (free tier)
- Webhooks: Cloudflare Workers

## Estrutura
- `index.html` - landing page
- `privacidade.html` - política de privacidade
- `termos.html` - termos de uso
- `assets/` - JS/CSS/images
- `video_pub_test.mp4` - vídeo hero
- `_redirects` - redirects do site

## Deploy
Conectado via GitHub Actions → Cloudflare Pages.

URL: https://andrecorreia01.com.br
